

## About the Project

FinTrust Digital Bank is a synthetic digital banking project focused on transforming customer and transaction data into useful business intelligence.

This repository documents my work on the Data Analytics track, from understanding the business problem through data exploration, KPI development, dashboard planning and business insights.

> Note: All FinTrust data used in this project is synthetic and intended for educational purposes.

## Week 1 – Understand & Plan

The first week focused on building a foundation for the analysis.

### What I Worked On

- Understanding the FinTrust business problem
- Reviewing the available resources
- Profiling customer and transaction data
- Identifying analytical questions
- Defining business KPIs
- Planning the dashboard
- Developing an initial analysis plan
- Identifying risks, assumptions and future dependencies

## Data

The project includes two main datasets:

### Customer Data

Contains customer-level information such as:

- Customer ID
- Age
- Gender
- City
- Customer Segment
- Account Type
- Tenure
- Digital Engagement
- Income Band
- Preferred Channel
- Account Status

### Transaction Data

Contains transaction-level information such as:

- Transaction ID
- Customer ID
- Transaction Date/Time
- Transaction Type
- Transaction Amount
- Channel
- Device Type
- Location
- International Transaction
- Transaction Status
- Risk Review Flag

## Initial Analytical Focus

The analysis will explore:

- Customer behaviour
- Customer engagement
- Transaction activity
- Transaction value
- Banking channels
- Transaction status
- Risk-review patterns
- Differences across customer segments
