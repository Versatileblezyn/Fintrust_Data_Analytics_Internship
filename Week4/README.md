# FinTrust Digital Bank - Week 4 Final Data Analytics Project

## Project Overview
This project presents the final review of the FinTrust Digital Bank Data Analytics track for the AnalystLab Africa Experience Lab.

The analysis covers synthetic customer and transaction data from 1 January to 31 March 2026.

## Tools Used
- SQL and PostgreSQL
- Python and pandas
- Power BI
- GitHub for project version control and documentation

## Key Results
- Customers: 1,500
- Transactions: 12,000
- Total transaction value: ₦560,477,354.85
- Average transaction value: ₦46,706.45
- Transaction success rate: 90.47%
- Synthetic review-flag rate: 19.60%
- Top 10% of transactions by value accounted for 56.15% of total transaction value.

## Main Deliverables
- Final SQL analysis and validation queries
- Final Python analysis notebook
- Final Power BI dashboard
- Final project report and documentation
- Final presentation

## Important Limitations
The dataset is synthetic and represents a fictional bank. The Risk_Review_Flag is an educational review indicator, not a confirmed fraud label. Findings should not be treated as production banking conclusions.

## Business Recommendations
1. Review international transaction review patterns.
2. Investigate unsuccessful transaction journeys by type and channel.
3. Monitor high-value transaction performance.
4. Maintain consistent KPI definitions across SQL, Python and Power BI.
